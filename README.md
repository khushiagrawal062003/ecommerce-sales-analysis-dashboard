# 📊 E-Commerce Data Analysis Project

## 🔍 Project Overview

This project focuses on analyzing e-commerce sales data to extract meaningful business insights using SQL, Python, and Power BI. The goal is to understand sales performance, customer behavior, product trends, and brand performance through data cleaning, querying, and visualization.

## 🛠 Tools & Technologies Used

- **SQL** – Data querying and analysis  
- **Python** – Data cleaning and preprocessing  
- **Power BI** – Interactive dashboard creation  
- **Excel / CSV** – Data storage and handling

## 📄 Data Source

The dataset used in this project is a sample e-commerce sales dataset created for educational and practice purposes. It contains information related to orders, product categories, brands, platforms, cities, pricing, quantities, and customer ratings.

## 🧹 Data Cleaning (Python)

- Handled missing and null values  
- Corrected data types (dates, numeric fields)  
- Removed inconsistencies and duplicates  
- Created calculated fields such as total sales and averages  
- Exported cleaned data for SQL and Power BI use

## 🧮 SQL Analysis

Using SQL, the following insights were generated:

- Total sales and order volume  
- Sales by category, brand, platform, and city  
- Average order value and customer ratings  
- Brand performance comparison  
- Time-based sales analysis

All SQL queries are stored in [`SQL/queries.sql`]

## 📈 Power BI Dashboard

An interactive dashboard was created featuring:

- KPI cards (Total Orders, Quantity, Sales, Avg Rating, Avg Order Value)  
- Sales trends over time  
- Category-wise and brand-wise sales  
- Platform and city performance  
- Scatter plot showing relationship between brand ratings and sales  
- Filters for year, month, city, and category

The dashboard allows dynamic filtering and easy business interpretation.

## 🎯 Key Insights

- Certain categories and brands contribute the highest revenue  
- Sales vary significantly by platform and city  
- Higher brand ratings generally correlate with better sales performance  
- Seasonal trends affect order volume and revenue
